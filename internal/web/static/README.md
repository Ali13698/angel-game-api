# پوشه Assets (کتابخانه‌های شخص ثالث)

این پوشه شامل کتابخانه‌های حیاتی فرانت‌اند است که به صورت لوکال (Local) در پروژه ذخیره شده‌اند تا مینی‌اپ‌های تلگرام و بله بدون نیاز به CDNهای خارجی و فیلترشکن، با بالاترین سرعت لود شوند.

## ⚠️ هشدار مهم برای AL بعدی (حافظه صفر):
تمام فایل‌های موجود در این پوشه **کامل، اصلی و آماده استفاده** هستند. 
*   **مطلقاً کدهای این فایل‌ها را تغییر ندهید.** (این‌ها فایل‌های فشرده یا Minified هستند).
*   نیازی به کپی کردن آن‌ها از هیچ مخزن دیگری نیست. این پوشه منبع نهایی و مستقل این کتابخانه‌هاست.

## لیست فایل‌ها:
1. `telegram-web-app.js` : کتابخانه رسمی تلگرام برای ارتباط با WebApp.
2. `protobuf.min.js` : کتابخانه ارتباط باینری (پروتوباف) برای WebSocket.
3. `cropper.min.js` : کتابخانه برش عکس برای آواتار پروفایل.
4. `cropper.min.css` : استایل مربوط به کتابخانه Cropper.
5. `angel.proto` : فایل قرارداد (Schema) پروتوباف برای ارتباط با هسته Go.
