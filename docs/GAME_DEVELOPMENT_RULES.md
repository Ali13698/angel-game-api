# قوانین توسعه بازی (WASM Sandbox)
۱. بازی یک ماشین حالت کور (Blind State Machine) است. نمی‌داند منچ است یا شطرنج.
۲. بازی هیچ دسترسی به شبکه، دیسک، PG، Redis یا MinIO ندارد.
۳. تمام اطلاعات (بازیکن‌ها، آیتم‌های فروشگاه، قوانین زمانی، چت) از هسته Go تزریق می‌شود.
۴. بازی فقط توابع Init (شروع)، Apply (حرکت) و GetView (نمایش) را دارد.
۵. آیتم‌های فروشگاه فقط اثرشان به بازی داده می‌شود (مثلاً قدرت تاس).
